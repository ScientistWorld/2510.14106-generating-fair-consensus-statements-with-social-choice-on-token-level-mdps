# Scientist Constraints

## Problem Setting

The scientist must evaluate on the provided synthetic token-tree setup unless they add a separately named experiment. The default benchmark uses branching factor 3, depth 4, five agents, and the tracked benchmark generator in `data/core_synthetic/generate.py`.

## Evaluation

The coalition-blocking LP in `eval/` must remain method-agnostic and must not import from `method/`. A submission must write the same artifact format: utility matrix, leaf list, and output distribution over leaves.

## Resources

Do not improve the score by increasing tree depth, branching factor, number of random seeds, or number of agents and reporting the result under the existing experiment name. Such changes create a different benchmark and must be listed as a new experiment.

## Compliance Checklist

- [ ] Uses the default synthetic token-tree benchmark for `empirical_core_test`
- [ ] Writes a distribution over the same leaf set generated by the benchmark
- [ ] Evaluation code does not import from `method/`
- [ ] No external data or model weights are used for the default score
